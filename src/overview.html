INSPECTOR

Live items: solids are tracked on belts, in inserter hands, and in machine buffers. Belt ends stop items unless an explicit external consumer is enabled. Bus belts start full. Other buffers start empty; editing a layout restarts the run. Live rates measure the last 30 seconds, including filling delays. Machine groups share input/output buffers; buffer sizes, arm timing, route transit and diagram distances are schematic estimates, not tile-accurate game timings. Fluids use continuous buffers, not Factorio pipe physics. The Budget remains a separate steady-state requirement calculation.

Belt types & model assumptions

Full supply and connected route are source labels, not different belt types. Both use the same conveyor. Yellow, red and blue are speed tiers. Wide tracks are belts; thin gold ↷ links are inserter transfers.

Budget calculation: continuous steady-state throughput. Normal quality; no modules or beacons. Filled input belts are external supplies. Open route ends continue out of this plan; storage accepts output continuously. Splitters preserve the two lanes, balance output where possible, and support branch priority. This is a schematic planner, not a tile-accurate game simulator: collisions, inserter reach, power, buffers and travel delays are not modeled. Belt marker spacing and passage frequency match steady-state items/min. Low flow creates gaps. Closed ends constrain production. A stationary packed end represents an inferred settled queue when opening that end would permit flow; exact stored quantities and filling time are not simulated. Zero throughput alone does not mean a backup. Open belt ends carry surplus out of the plan. Segments show steady-state streams; item identities, startup delays, transient queues and exact inserter swings are not simulated.

Transfers have editable throughput limits. Pickups along a shared lane have upstream priority. Conflicting shared-resource priorities use creation order. Feedback loops are not supported. Up to 40 nodes / 100 links.
